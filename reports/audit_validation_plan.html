New Issues Discovered

NEW-001 — Operators absorbed into the exponent during exponent entry Medium

inputOperator() marks pressed binary operators isExponent: true while exponentMode is active, and rawExpression() collects them into the parenthesized exponent. Reproduced: 5 → xʸ → 2 → + → 3 → = → raw 5^(2+3) → 3125 (user expects 28), rendered as 5²⁺³. Same family as AUD-003/004; conflicts with iOS-calculator muscle memory and README §7/§14.6 contradiction.
Remediation: binary arithmetic operators (+ - × ÷) close exponent mode (recommended), or keep + document as unified behavior, or render operators non-superscript if kept. Coordinate with the AUD-004 helper.

NEW-002 — evaluate() auto-closes parens even when evaluation fails Low

Runtime repro: (5÷0 + = → error "Division by zero", but token stream permanently gains the phantom ) ((5÷0)); backspace then removes the phantom instead of the user's char; error display shows tokens the user never typed.
Remediation: evaluate a copy of the auto-closed tokens; commit only on success. Zero-UX-change.

NEW-003 — Forced synchronous layout in render path each keystroke Low

autoShrinkToFit() writes style.fontSize then reads scrollWidth/clientWidth (layout thrash, up to 4 forced layouts per render incl. both displays); scrollToDisplayEnd() adds two more read/write pairs; resize/orientationchange trigger unthrottled full re-renders.
Remediation: batch reads before writes, cache computed styles, offscreen measurement, requestAnimationFrame-throttled resize. Validate with DevTools Performance (no forced-sync-layout per keypress).

NEW-004 — Manifest locks installed PWA to portrait while landscape CSS exists Low

manifest.json "orientation": "portrait" vs a complete landscape 6×4 stylesheet (style.css:518-609) and orientationchange render wiring. Android standalone will lock portrait (landscape CSS dead code); iOS ignores it — inconsistent.
Remediation: set "orientation": "any" (recommended) or drop landscape CSS; document the choice.

NEW-005 — History overlay statically aria-hidden but becomes clickable when open Low

index.html:105 hardcodes aria-hidden="true"; toggleHistoryPanel() never updates it while .is-open makes it a live click-to-close target.
Remediation: sync or drop aria-hidden on the overlay (fold into AUD-007 fix).

NEW-006 — Multi-tab history last-write-wins silently discards entries Low

No storage event handling anywhere; two tabs each rewrite the full list and erase each other's entries written since their own last =.
Remediation: window.addEventListener('storage', …) + HistoryManager.reload() (using the AUD-009 validator), merging by id; or reload the list at minimum.
